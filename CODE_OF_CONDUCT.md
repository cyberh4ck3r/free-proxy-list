# Code of Conduct

## our pledge

we pledge to make participation in this project a harassment-free experience for everyone.

## standards

- be respectful and constructive
- no harassment, hate speech or spam
- stay on topic (proxy aggregation, health-check, filters)

## enforcement

violations can be reported via GitHub issue or Security tab. maintainers will review and take appropriate action.

## attribution

based on the Contributor Covenant, adapted for this project.
